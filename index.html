02 / TRAIN

Prepare a real LoRA

Ostris AI Toolkit

Export creates image files plus matching caption .txt files. Review captions before training. The ZIP is not a trained LoRA.

Free cloud GPU training instructions

Open Kaggle Notebooks or Google Colab. Free GPU access, runtime policies and availability change. Use an official, permitted notebook environment and follow the AI Toolkit repository's current setup. Upload your ZIP, choose a base model supported by the available GPU memory, train, then download your .safetensors LoRA. Training may not fit free hardware or may time out; no automated training is claimed here.

03 / MODEL

Keep your trained LoRA

Once training finishes, save the .safetensors file to your iPhone Files app. You can register its name here for your own records. Large model weights are not uploaded or hosted by this site.

04 / CREATE

Plan new photos

Write a scene, then copy a ready-to-use prompt for a compatible image-generation workflow. Image generation requires a GPU running a compatible base model plus your LoRA; it cannot run inside this static site on an iPhone.

ComfyUI

For actual generation, load the exact compatible base model and your LoRA in ComfyUI on an available GPU. Save each output separately. No fake generation previews.

05 / GALLERY

Your finished photos

Import images you generated elsewhere to keep a local gallery here. Each image is stored separately in your browser.
